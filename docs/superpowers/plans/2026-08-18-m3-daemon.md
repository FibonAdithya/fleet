# M3 Daemon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the imperative shell around M2's tested `decide()` — a daemon that ticks, a `HerdrExecutor` that starts real agents in real worktrees, a state socket with `fleet status` as its client, and an integrator that merges — and drive one real issue from READY to DONE with the daemon killed and restarted in the middle.

**Architecture:** M2's `Executor` protocol is the seam and does not move. `HerdrExecutor` implements it by composing four single-dependency units (`Herdr`, `Cost`, an extended ledger read, and `gh`), each with its own fake. The pure core gains five changes, all of them forced by M3 being the first milestone in which issues actually get closed and handoff packets actually get fetched. Tasks 1–8 change the pure core and touch no I/O; tasks 9–17 build the shell; tasks 18–22 make the fixture re-runnable and run the gate live.

**Tech Stack:** Python 3.10+, `click`, `pytest`, `ruff`, `uv`. External processes: `gh` (GitHub CLI), `git`, `herdr`. Target host: `tig-server` (2 vCPU, 3.7 GB, no GPU, no Docker).

**Spec:** `docs/superpowers/specs/2026-08-18-m3-daemon-design.md`

## Global Constraints

- **`make check` must be green at the end of every task.** It is `uv run ruff check . && uv run ruff format --check . && uv run pytest`. Baseline at the start of this plan: **343 passed**.
- **The per-task test counts are expectations, not assertions.** They assume every test written exactly as given. Landing a few above or below is fine; landing *below the previous task's count* is not — that means something regressed, and it is a finding, not a rounding error.
- **M2's seven scenarios must keep passing untouched** (`uv run pytest tests/test_scenarios.py`). They are the regression signal that the pure-core changes did not reshape the core underneath them. If a scenario file needs editing, stop and raise it — that is a finding, not a chore.
- **Never weaken a fake to make a test pass.** `docs/m2-inputs.md` §6: four `FakeGh`/`RealGh` divergences were found in M1 and every one would have passed the entire offline suite and failed against GitHub. A fake must be *less* permissive than the real client, never more.
- **Every new fake is tested against a captured real artefact.** Captures live in `fixtures/` and are checked in.
- **The pure core stays pure.** `src/fleet/decide.py` and `src/fleet/expand.py` import no I/O, take no clock, and open no sockets. Time enters as `now`.
- **Commit at the end of every task**, with explicit paths. Never `git add -A`, `git add .`, or `git commit -a`.
- **Python version floor is 3.10** — `src/fleet/config.py` has a `tomllib`/`tomli` fallback for it. Do not use `match` statements or 3.11+ syntax.
- **Budget defaults**, unchanged: `per_task_usd = 2.0`, `fleet_usd = 25.0`, `slots = 6`, `stall_minutes = 10`, `max_attempts = 2`, `max_fix_passes = 1`. New in this plan: `max_rebases = 1`.

```python
@dataclass(frozen=True)
class Retire:
    """Stop an agent that has already written its own state transition.

    An implementer ends its stage by running `fleet handoff --to review`, which
    moves the label itself, and then exits. There is nothing to advance -- the
    move already happened -- and nothing to release, because the task did not
    fail. Without this intent the exited agent stays in herdr's snapshot, keeps
    `_dispatch`'s `busy` set counting it, and holds the slot for the night.

    No state field on purpose: this intent must not be able to express a
    relabel, because the label is the one thing the agent got right.
    """

    task: int
```

And extend the union:

```python
def test_a_finished_agent_on_a_reviewing_task_is_retired():
    """The implementer ran `fleet handoff --to review`, which moved the label
    itself, then exited. REAP used to skip every non-CLAIMED row, so this agent
    was never stopped: it stayed in the snapshot, kept _dispatch's `busy` set
    counting it, and the task could never reach a reviewer."""
    task = _task(number=5, state="review")
    agents = [AgentState(task=5, status="done", change_seq=3, cost_usd=0.5)]
    intents, _ = decide(FleetState(), [task], POLICY, agents, NOW)
    assert Retire(task=5) in intents
    assert not any(isinstance(i, (Release, Advance)) for i in intents)


def test_a_working_agent_on_a_reviewing_task_is_left_alone():
    """A reviewer mid-review is not a leak. Retiring on presence rather than on
    an exited status would kill every reviewer one tick after it started."""
    task = _task(number=5, state="review")
    agents = [AgentState(task=5, status="working", change_seq=3)]
    intents, _ = decide(FleetState(), [task], POLICY, agents, NOW)

def test_a_stalled_reviewer_escalates_rather_than_releasing():
    """_fail relabels to READY, which would restart the task from its
    implementer and throw away a review that already happened. Escalate is
    bounded and terminal; a stage that failed after the work was done is a
    human's problem."""
    task = _task(number=5, state="review")
    first = [AgentState(task=5, status="working", change_seq=3)]
    _, state = decide(FleetState(), [task], POLICY, first, NOW)
    later = NOW + timedelta(minutes=POLICY.stall_minutes + 1)
    intents, _ = decide(state, [task], POLICY, first, later)
    assert intents == [Escalate(task=5, reason="stalled")]
```

```python
def _unroutable(ledger: list[Task], policy: Policy) -> list[Intent]:
    """Dispatchable tasks the policy cannot route. A human is the only fix.

    Two distinct policy errors, named apart because the run log is where an
    operator finds out which one it was: `unroutable` is a task whose class has
    no route at all -- a missing `class:` label, or a class absent from
    task-classes.md. `unroutable_stage` is a task that reached a state its route
    has no role for, which is the failure M4's invariant reviewer will produce if
    it is added to a route without its state.

    Its own phase rather than a branch in `_dispatch`, so the escalation is not
    gated on a free slot or a free area: it is a fact about the policy, not about
    capacity, and a full fleet would otherwise hide the misconfiguration for
    exactly as long as it stayed busy.

    `auto_ok` is required. Its absence is a human's decision not to run this task
    unattended, which is why it is sitting there -- escalating that is noise.
    """
    out: list[Intent] = []
    for task in ledger:
        if task.state not in _STAGE or not task.auto_ok:
            continue
        if not policy.route_for(task.klass):
            out.append(Escalate(task=task.number, reason="unroutable"))
        elif _role_for(task, policy) is None:
            out.append(Escalate(task=task.number, reason="unroutable_stage"))
    return out
```

```python
"""Transcript tokens -> dollars. Pure.

herdr reports no cost and Claude Code writes no dollar figure, but every agent in
a herdr snapshot carries `agent_session.value` -- the Claude session UUID -- and
the transcript is `~/.claude/projects/<slug>/<uuid>.jsonl`. Verified against the
captured snapshot: 10 of 10 agents resolved to a transcript.

No herdr, no network, no clock. The budget ceiling is the part of M3 most likely
to be quietly wrong, so it is the part that gets a pure function.
"""

from __future__ import annotations

import json
from pathlib import Path

# fleet.toml's [prices] tables are keyed by model and carry these four rates, in
# dollars per million tokens. The mapping to Claude Code's counter names lives
# here and nowhere else.
_COUNTERS = {
    "input": "input_tokens",
    "output": "output_tokens",
    "cache_read": "cache_read_input_tokens",
    "cache_write": "cache_creation_input_tokens",
}

PRICE_KEYS = tuple(_COUNTERS)

_PER = 1_000_000


class UnpricedModel(Exception):
    """A transcript names a model the price table does not.

    Raised rather than defaulted to zero: a zero price switches the ceiling off
    silently, and the event that causes it -- a model changing under an agent --
    happens without anyone editing fleet.toml. The daemon's response is to drain,
    which is what parent §10 already prescribes for a budget it cannot honour.
    """


def price_lines(lines: list[str], prices: dict[str, dict[str, float]]) -> float:
    total = 0.0
    for raw in lines:
        raw = raw.strip()
        if not raw:
            continue
        try:
            entry = json.loads(raw)
        except ValueError:
            # A transcript being appended to while we read it ends mid-line.
            # Skipping the partial line costs one message of accuracy for one
            # tick; crashing costs the whole tick.
            continue
        if not isinstance(entry, dict):
            continue
        message = entry.get("message") or {}
        usage = message.get("usage")
        if not usage:
            continue
        model = message.get("model")
        table = prices.get(model)
        if table is None:
            raise UnpricedModel(
                f"no price for model {model!r}. Add it to [prices] in fleet.toml. "
                "Pricing it at zero would disable the budget ceiling instead."
            )
        for key, field in _COUNTERS.items():
            total += (usage.get(field) or 0) * table[key] / _PER
    return total


def price_transcript(path: Path, prices: dict[str, dict[str, float]]) -> float:
    return price_lines(Path(path).read_text(encoding="utf-8").splitlines(), prices)


def transcript_path(session_id: str, projects_dir: Path) -> Path | None:
    """`~/.claude/projects/*/<uuid>.jsonl`, or None.

    None when herdr knows about an agent whose transcript has not been written
    yet -- ordinary in the seconds after a dispatch. A fact about the filesystem,
    not an error: raising here would take down a tick over a race.
    """
    hits = sorted(Path(projects_dir).glob(f"*/{session_id}.jsonl"))
    return hits[0] if hits else None
```

```python
def _prices(raw: dict) -> dict[str, dict[str, float]]:
    """Dollars per million tokens, by model.

    Every table must carry all four counters. Three of four is the same silent
    hole as an unpriced model: the missing rate prices those tokens at nothing,
    and cache reads are most of what an agent spends.

    An absent [prices] table is an empty mapping, not an error. `fleet plan
    --dry-run` starts no agents and needs no prices; only the daemon does, and
    it fails loudly at the first agent it cannot price.
    """
    out: dict[str, dict[str, float]] = {}
    for model, table in raw.items():
        missing = [key for key in PRICE_KEYS if key not in table]
        if missing:
            raise ConfigError(
                f"[prices.{model!r}] is missing {', '.join(missing)}. "
                "A rate left out prices those tokens at zero, which is the hole "
                "the ceiling exists to close."
            )
        out[model] = {key: float(table[key]) for key in PRICE_KEYS}
    return out
```

```python
"""The herdr seam. RealHerdr shells out; FakeHerdr is in memory.

Same shape as `gh.py`, for the same reason: four of M0-M1's defects were cases
where the fake was subtly more permissive than the real client, and every one of
them passed the whole offline suite (docs/m2-inputs.md §6).

A task's agent is identified by its worktree path, not by anything herdr stores:
the snapshot carries no issue number. The executor chooses the path, so the
daemon can parse it -- which is what makes a restart cheap, because the answer to
"who is working on #1" is a directory on disk plus a label on GitHub, and both
survive kill -9.
"""

from __future__ import annotations

import json
import re
import subprocess
from pathlib import Path
from typing import Protocol

from fleet.cost import price_transcript, transcript_path
from fleet.model import AgentState

# herdr's five statuses to AgentState's three.
#
# `blocked` is dirty rather than working: it means the agent is waiting for input
# nothing will give it -- a permission prompt, which parent §8 names as the most
# common cause of a stall. Waiting stall_minutes to notice what herdr has already
# told us is ten wasted minutes per occurrence.
#
# `idle` is done: the dispatcher submits exactly one prompt, so an agent back at
# idle has finished that turn and written whatever packet it was going to write.
#
# `unknown` is working: herdr saying it cannot tell is not evidence of failure.
# Treating it as one would release healthy agents; a real hang is still caught by
# the stall timer, which is what that timer is for.
STATUS = {
    "working": "working",
    "unknown": "working",
    "idle": "done",
    "done": "done",
    "blocked": "dirty",
}

_LEADING_NUMBER = re.compile(r"^(\d+)(?:-|$)")


class HerdrError(RuntimeError):
    """Anything the herdr client could not do."""


def task_of(checkout_path: str, worktree_root: Path) -> int | None:
    """`<worktree_root>/<n>-<slug>` -> n, else None.

    None for every workspace outside the fleet's own worktree root. A human's
    herdr session on the same box must not be read as a fleet agent: it would be
    counted against `slots` and REAP would try to stop it.
    """
    try:
        relative = Path(checkout_path).resolve().relative_to(Path(worktree_root).resolve())
    except ValueError:
        return None
    if not relative.parts:
        return None
    match = _LEADING_NUMBER.match(relative.parts[0])
    return int(match.group(1)) if match else None


def parse_snapshot(
    raw: dict,
    worktree_root: Path,
    projects_dir: Path | None = None,
    prices: dict[str, dict[str, float]] | None = None,
) -> list[AgentState]:
    """herdr's snapshot JSON -> AgentState, cost joined.

    `cwd` rather than the workspace's `worktree.checkout_path`: the agent record
    carries it directly, and going via `workspace_id` would silently drop an
    agent whose workspace is missing from the same snapshot.
    """
    agents = (raw.get("result") or {}).get("snapshot", {}).get("agents", [])
    out: list[AgentState] = []
    for agent in agents:
        task = task_of(agent.get("cwd") or "", worktree_root)
        if task is None:
            continue
        status = STATUS.get(agent.get("agent_status"), "working")
        session = (agent.get("agent_session") or {}).get("value")
        cost = 0.0
        if session and projects_dir is not None and prices:
            path = transcript_path(session, projects_dir)
            if path is not None:
                cost = price_transcript(path, prices)
        out.append(
            AgentState(
                task=task,
                status=status,
                change_seq=int(agent.get("state_change_seq", 0)),
                cost_usd=cost,
            )
        )
    return sorted(out, key=lambda a: a.task)


class Herdr(Protocol):
    def agents(self) -> list[AgentState]: ...
    def create_worktree(self, task: int, slug: str, base: str) -> Path: ...
    def remove_worktree(self, task: int) -> None: ...
    def start_agent(self, task: int, role: str, prompt: str) -> None: ...
    def stop_agent(self, task: int) -> None: ...


class FakeHerdr:
    """In-memory, with the same surface. The only client tests use."""

    def __init__(self, worktree_root: Path | None = None) -> None:
        self.root = Path(worktree_root or "/fake/worktrees")
        self._agents: dict[int, AgentState] = {}
        self.worktrees: dict[int, Path] = {}
        self.started: list[tuple[int, str, str]] = []
        self.stopped: list[int] = []
        self.removed: list[int] = []

    def add_agent(self, task: int, status: str, change_seq: int, cost_usd: float = 0.0) -> None:
        if status not in ("working", "done", "dirty"):
            # A typo would otherwise script a working agent and the test would
            # pass while proving nothing -- the same guard FakeExecutor.script has.
            raise ValueError(f"unknown status {status!r}")
        self._agents[task] = AgentState(
            task=task, status=status, change_seq=change_seq, cost_usd=cost_usd
        )

    def agents(self) -> list[AgentState]:
        return sorted(self._agents.values(), key=lambda a: a.task)

    def create_worktree(self, task: int, slug: str, base: str) -> Path:
        path = self.root / f"{task}-{slug}"
        self.worktrees[task] = path
        return path

    def remove_worktree(self, task: int) -> None:
        self.worktrees.pop(task, None)
        self.removed.append(task)

    def start_agent(self, task: int, role: str, prompt: str) -> None:
        self.started.append((task, role, prompt))
        self.add_agent(task, "working", change_seq=len(self.started))

    def stop_agent(self, task: int) -> None:
        self._agents.pop(task, None)
        self.stopped.append(task)
```

```python
class RecordingRun:
    """Captures argv instead of running it. RealHerdr is never executed in the
    offline suite, so what it BUILDS is the only thing a test can pin -- and a
    wrong flag here is a failure that only ever shows up at 2am."""

    def __init__(self, replies=None):
        self.calls = []
        self.replies = replies or {}

    def __call__(self, *args):
        self.calls.append(args)
        return self.replies.get(args[0], "")

        worktree_root=tmp_path / "worktrees",

        repo_root=tmp_path / "repo",
```

```python
class RealHerdr:
    """Shells out to `herdr` and `git`. Never used in the offline suite.

    `_run` is an attribute rather than a method call site so a test can record
    argv without executing it: what this class BUILDS is the only thing an
    offline test can check, and a wrong flag is a failure that shows up at 2am.
    """

    def __init__(
        self,
        worktree_root: Path,
        projects_dir: Path,
        prices: dict[str, dict[str, float]],
        repo_root: Path,
        agent_kind: str = "claude",
        agent_args: tuple[str, ...] = ("--permission-mode", "acceptEdits"),
    ) -> None:
        self.root = Path(worktree_root)
        self.projects_dir = Path(projects_dir)
        self.prices = prices
        self.repo_root = Path(repo_root)
        self.agent_kind = agent_kind
        self.agent_args = agent_args
        self.worktrees: dict[int, Path] = {}
        self._run = self._subprocess

    def _subprocess(self, *args: str) -> str:
        try:
            return subprocess.run(
                args, capture_output=True, text=True, check=True
            ).stdout.strip()
        except subprocess.CalledProcessError as exc:
            # Same reasoning as RealGh._run and git._git: CalledProcessError
            # carries argv and exit code but not stderr, which is where the
            # reason is.
            raise HerdrError(f"{' '.join(args)} failed: {exc.stderr.strip()}") from exc

    def agents(self) -> list[AgentState]:
        raw = json.loads(self._run("herdr", "api", "snapshot"))
        return parse_snapshot(raw, self.root, self.projects_dir, self.prices)

    def create_worktree(self, task: int, slug: str, base: str) -> Path:
        path = self.root / f"{task}-{slug}"
        # Fetch first. Parent §8.2's fresh-base rule is this line: branching off
        # a stale local `integration` reproduces exactly the staleness the
        # integration branch exists to remove.
        self._run("git", "-C", str(self.repo_root), "fetch", "origin", base)
        self._run(
            "herdr", "worktree", "create",
            "--cwd", str(self.repo_root),
            "--branch", f"fleet/{task}-{slug}",
            "--base", f"origin/{base}",
            "--path", str(path),
            "--label", f"fleet-{task}",
        )
        self.worktrees[task] = path
        return path

    def remove_worktree(self, task: int) -> None:
        path = self.worktrees.get(task) or self._existing(task)
        if path is None:
            return
        self._run("herdr", "worktree", "remove", str(path))
        self.worktrees.pop(task, None)

    def _existing(self, task: int) -> Path | None:
        """A worktree this process did not create -- after a daemon restart, or
        an orphan whose task is no longer live. Found on disk rather than in
        memory, for the same reason task identity is a path: memory does not
        survive a restart and the disk does."""
        for candidate in sorted(self.root.glob(f"{task}-*")):
            return candidate
        return None

    def start_agent(self, task: int, role: str, prompt: str) -> None:
        path = self.worktrees[task]
        pane = self._run("herdr", "pane", "list", "--cwd", str(path)).splitlines()
        pane_id = pane[0].split()[0] if pane else self._open_pane(path)
        # Exported into the pane BEFORE the agent starts: the CLI reads them at
        # the moment a packet is written, and an unset FLEET_AGENT attributes
        # that packet to 'manual' -- indistinguishable from a human at a
        # keyboard, which is what makes it a silent dispatch bug.
        self._run(
            "herdr", "agent", "send-keys", pane_id,
            f"export FLEET_ROLE={role} FLEET_AGENT=fleet-{task}\n",
        )
        self._run(
            "herdr", "agent", "start", f"fleet-{task}",
            "--kind", self.agent_kind,
            "--pane", pane_id,
            "--", *self.agent_args,
        )
        self._run("herdr", "agent", "prompt", f"fleet-{task}", prompt)

    def _open_pane(self, path: Path) -> str:
        return self._run("herdr", "workspace", "open", "--cwd", str(path))

    def stop_agent(self, task: int) -> None:
        """Stops the agent and leaves the worktree alone.

        Separate from remove_worktree on purpose: a released task's branch holds
        the work it did before it stalled, and fusing the two would delete a
        task's commits every time an agent was released.
        """
        self._run("herdr", "agent", "send-keys", f"fleet-{task}", "\\x03")
```

```python
"""The real executor. Composes herdr, gh and the prompt layer behind M2's seam.

M2's `Executor` protocol is `apply(effects)` and `agents()`, and it does not
move: FakeExecutor and all seven scenarios stand on it, and they are M2's whole
deliverable. Everything real happens on this side of it.
"""

from __future__ import annotations

import json
import re
from pathlib import Path

from fleet import packet as packet_module
from fleet.config import FleetConfig
from fleet.gh import GhClient
from fleet.herdr import Herdr
from fleet.model import AgentState, Assign, CloseIssue, Effect, SetLabels, StartAgent, StopAgent

_UNSAFE = re.compile(r"[^a-z0-9]+")
_SLUG_MAX = 48


def slug_of(title: str) -> str:
    """A branch and directory name. Bounded, lowercase, no separators.

    It becomes `fleet/<n>-<slug>` and `<worktree_root>/<n>-<slug>`: a slash would
    make a nested ref, a space would need quoting in every shell call downstream,
    and a 200-character issue title makes a path some filesystems refuse.
    """
    return _UNSAFE.sub("-", title.lower()).strip("-")[:_SLUG_MAX].strip("-")


def build_prompt(cfg: FleetConfig, gh: GhClient, task: int, role: str) -> str:
    """Role prompt + issue body + latest handoff packet + AGENTS.md. Nothing else.

    Parent §7.2 is exact about the list, and parent §6's zero-history test is
    enforced by this function's construction rather than by anyone's discipline.
    Every extra thing added here weakens that test silently -- the packet stops
    having to be sufficient, and nobody finds out until the packet is the only
    thing a receiver gets.

    A missing role prompt raises. An agent handed an empty role does something
    plausible and wrong, and a blank prompt buries the policy error that caused
    it.
    """
    role_prompt = (cfg.roles_dir / f"{role}.md").read_text(encoding="utf-8")
    issue = gh.get_issue(task)
    agents_md = ""
    candidate = cfg.root / "AGENTS.md"
    if candidate.is_file():
        agents_md = candidate.read_text(encoding="utf-8")
    latest = packet_module.latest(issue.get("comments") or [])
    parts = [
        role_prompt,
        f"# Issue #{task}: {issue.get('title', '')}\n\n{issue.get('body', '')}",
    ]
    if latest is not None:
        parts.append("# Handoff packet\n\n```json\n" + json.dumps(latest, indent=2) + "\n```")
    if agents_md:
        parts.append(agents_md)
    return "\n\n---\n\n".join(parts)


class HerdrExecutor:
    """Implements M2's Executor against real worktrees, agents and GitHub."""

    def __init__(
        self, herdr: Herdr, gh: GhClient, cfg: FleetConfig, owner: str | None = None
    ) -> None:
        self.herdr = herdr
        self.gh = gh
        self.cfg = cfg
        self.owner = owner

    def agents(self) -> list[AgentState]:
        return self.herdr.agents()

    def apply(self, effects: list[Effect]) -> None:
        for effect in effects:
            if isinstance(effect, SetLabels):
                # Add first. expand._to_state excludes the added label from
                # `remove` precisely so this order is safe; reversed, a failure
                # between the two calls strands the task with no state label at
                # all, invisible to every label query.
                self.gh.add_labels(effect.task, list(effect.add))
                self.gh.remove_labels(effect.task, list(effect.remove))
            elif isinstance(effect, Assign):
                self.gh.assign(effect.task, effect.owner)
            elif isinstance(effect, CloseIssue):
                self.gh.close_issue(effect.task)
            elif isinstance(effect, StartAgent):
                self._start(effect)
            elif isinstance(effect, StopAgent):
                # The worktree goes with the agent. A re-dispatch creates one at
                # the same path on the same branch, and a leftover makes that
                # create fail -- turning one stall into a task that never runs
                # again.
                self.herdr.stop_agent(effect.task)
                self.herdr.remove_worktree(effect.task)
            else:
                raise ValueError(f"cannot apply {effect!r}")

    def _start(self, effect: StartAgent) -> None:
        issue = self.gh.get_issue(effect.task)
        self.herdr.create_worktree(effect.task, slug_of(issue.get("title", "")), effect.base)
        # Ownership is written here because this is the layer that knows the
        # identity gh is authenticated as. `fleet-1` is not a GitHub login, and
        # gh fails the whole edit on an assignee it cannot resolve.
        if self.owner:
            self.gh.assign(effect.task, self.owner)
        self.herdr.start_agent(
            effect.task, effect.role, build_prompt(self.cfg, self.gh, effect.task, effect.role)
        )
```

```python
"""The daemon's ledger read: rows, plus packets for the rows that carry one.

Split out of the CLI's `do_plan` because it needs two things `do_plan` does not:
the `all` query, and comment bodies. Both are M3-only, and both are things
m2-inputs §7 names as inherited debt.
"""

from __future__ import annotations

from fleet import ledger as ledger_module
from fleet import packet as packet_module
from fleet.gh import GhClient
from fleet.model import Task

# The states whose rows carry a packet worth fetching.
#
# `blocked` is here because `Task.blocked_on` comes from the packet and nothing
# else -- without it UNBLOCK has no input at all. `ready` and `done` are not:
# nothing reads a packet in either state, and `gh issue view` is one API call per
# issue, so fetching for every row turns one list call into fifty.
PACKET_STATES = ("claimed", "review", "integrating", "blocked")


def read_ledger(gh: GhClient) -> list[Task]:
    """Every row, open and closed, with packets for the states that carry one.

    `all`, not `open`. Once packets are fetched, `blocked_on` is populated and
    UNBLOCK becomes reachable -- and an open-only query drops the closed
    dependency that would satisfy it, reintroducing the same wedge from the
    query side that the `_open` split removes from the filter side.

    Closed rows are returned rather than filtered: three phases in `decide()`
    disagree about what a closed row means, and filtering here would take that
    choice away from the only code that can make it.
    """
    rows = gh.list_issues("all")
    packets: dict[int, dict] = {}
    for row in rows:
        shallow = ledger_module.read_one(row)
        if shallow.state not in PACKET_STATES:
            continue
        found = packet_module.latest(gh.get_issue(row["number"]).get("comments") or [])
        if found is not None:
            packets[row["number"]] = found
    return ledger_module.read(rows, packets)
```

```python
def spent_from_log(path: Path, run_id: str | None = None) -> float:
    """Rebuild `FleetState.spent_usd` from the log.

    Derived and disposable, still -- but reconstructible, which is what parent
    §9's "holds no authoritative state" always meant. A missing file is zero: a
    fresh fleet has not written one yet, and raising would stop the daemon
    starting.

    Tolerant of a truncated final line, because a daemon killed mid-write is
    precisely the event this exists to recover from.
    """
    path = Path(path)
    if not path.is_file():
        return 0.0
    total = 0.0
    for line in path.read_text(encoding="utf-8").splitlines():
        line = line.strip()
        if not line:
            continue
        try:
            entry = json.loads(line)
        except ValueError:
            continue
        if run_id is not None and entry.get("run_id") != run_id:
            continue
        total += float(entry.get("cost_usd") or 0.0)
    return total
```

```python
@dataclass(frozen=True)
class FleetSnapshot:
    """One completed tick, rendered. Derived and disposable.

    Published by swapping a single reference, so the socket thread can never
    observe a half-written tick and needs no lock. Nothing authoritative lives
    here: losing it costs a client one refresh.
    """

    run_id: str
    tick: int
    at: str
    rows: tuple[dict, ...]
    spent_usd: float
    fleet_usd: float
    free_slots: int
    held_areas: tuple[str, ...]
    draining: bool = False
    drain_reason: str = ""

    def to_json(self) -> dict:
        return {
            "run_id": self.run_id,
            "tick": self.tick,
            "at": self.at,
            "rows": [dict(row) for row in self.rows],
            "spent_usd": self.spent_usd,
            "fleet_usd": self.fleet_usd,
            "free_slots": self.free_slots,
            "held_areas": list(self.held_areas),
            "draining": self.draining,
            "drain_reason": self.drain_reason,
        }
```

```python
"""The tick loop. A thin imperative shell around an already-tested core.

Holds no authoritative state. Task state lives in labels, ownership in the
assignee, and the night's spend is rebuilt from the run log -- so a restart costs
one thing: idle timers start again, and a stall in progress is noticed up to
stall_minutes late.
"""

from __future__ import annotations

import threading
from datetime import datetime

from fleet import runlog as runlog_module
from fleet.config import FleetConfig
from fleet.decide import REAPING, decide
from fleet.expand import expand
from fleet.gh import GhClient
from fleet.model import Drain, Effect, FleetSnapshot, FleetState, Intent, Policy
from fleet.reader import read_ledger
from fleet.runlog import RunLog

_LIVE_STATES = ("claimed", "review", "integrating")


class Daemon:
    def __init__(
        self,
        cfg: FleetConfig,
        policy: Policy,
        gh: GhClient,
        executor,
        runlog: RunLog,
        run_id: str,
    ) -> None:
        self.cfg = cfg
        self.policy = policy
        self.gh = gh
        self.executor = executor
        self.runlog = runlog
        self.run_id = run_id
        self.tick_number = 0
        self.snapshot: FleetSnapshot | None = None
        # The restart's whole memory. Scoped to this run id because one log file
        # holds several nights, and summing all of them starts tonight drained.
        self.state = FleetState(
            spent_usd=runlog_module.spent_from_log(runlog.path, run_id=run_id)
        )

    def tick(self, now: datetime) -> FleetSnapshot:
        self.tick_number += 1
        ledger = read_ledger(self.gh)
        agents = self.executor.agents()
        unpriced = sorted(self.executor.unpriced())
        intents, state = decide(self.state, ledger, self.policy, agents, now)

        if unpriced:
            # Drain, do not kill. Dropping the dispatches stops new spend; the
            # reap is kept because a stalled agent still needs noticing while a
            # human fixes the price table. Pricing the unknown model at zero
            # instead would run the whole night with no ceiling at all.
            intents = [i for i in intents if not isinstance(i, Dispatch)]
            intents.append(Drain(reason=f"unpriced_model: {'; '.join(unpriced)}"))

        cost_of = {a.task: a.cost_usd for a in agents}
        effects: list[Effect] = []
        for intent in intents:
            final = cost_of.get(getattr(intent, "task", None), 0.0) if isinstance(
                intent, REAPING
            ) else 0.0
            self.runlog.append(
                tick=self.tick_number, at=now, intent=intent, outcome="applied", cost_usd=final
            )
            effects += expand(intent, self.policy)
        self.executor.apply(effects)

        self.state = state
        self.snapshot = self._render(ledger, agents, now, intents, unpriced)
        return self.snapshot

    def _render(self, ledger, agents, now, intents, unpriced) -> FleetSnapshot:
        by_task = {a.task: a for a in agents}
        live = [t for t in ledger if t.state in _LIVE_STATES and t.is_open]
        rows = tuple(
            {
                "task": t.number,
                "title": t.title,
                "state": t.state,
                "area": t.area,
                "class": t.klass,
                "attempt": t.attempts,
                "rebases": t.rebases,
                "owner": t.assignee,
                "agent": by_task[t.number].status if t.number in by_task else None,
                "cost_usd": round(by_task[t.number].cost_usd, 4) if t.number in by_task else 0.0,
            }
            for t in sorted(ledger, key=lambda t: t.number)
            if t.is_open and t.state != "triage"
        )
        draining = bool(unpriced) or any(isinstance(i, Drain) for i in intents)
        reason = next(
            (i.reason for i in intents if isinstance(i, Drain)), ""
        )
        return FleetSnapshot(
            run_id=self.run_id,
            tick=self.tick_number,
            at=now.isoformat(),
            rows=rows,
            spent_usd=round(self.state.spent_usd, 4),
            fleet_usd=self.policy.fleet_usd,
            free_slots=max(0, self.policy.slots - len({t.number for t in live} | set(by_task))),
            held_areas=tuple(sorted({t.area for t in live if t.area})),
            draining=draining,
            drain_reason=reason,
        )

    def run(self, poll_seconds: float, stop: threading.Event, publish=None) -> None:
        """Ticks until `stop` is set.

        An event rather than a signal handler or a kill: a graceful stop has to
        be distinguishable from the crash the restart test needs to simulate, and
        `stop.wait` also makes the sleep interruptible so a shutdown does not
        block for a whole poll interval.
        """
        while not stop.is_set():
            snapshot = self.tick(_utcnow())
            if publish is not None:
                publish(snapshot)
            stop.wait(poll_seconds)


def _utcnow() -> datetime:
    from datetime import timezone

    return datetime.now(timezone.utc)
```

```python
"""The state socket. Newline-delimited JSON over a Unix domain socket.

Named `statesocket` rather than `socket` so it cannot shadow the stdlib module
it imports.

Parent §2: if the client were the orchestrator, closing it would stop the fleet.
So the daemon owns the loop and clients attach and detach. Nothing authoritative
lives here -- the socket serves a render of the last completed tick, and losing
it costs a client one refresh.
"""

from __future__ import annotations

import contextlib
import json
import socket
import threading
from pathlib import Path

_TIMEOUT = 0.5
_BACKLOG = 8


class NotRunning(Exception):
    """No daemon is listening on that socket."""


def serve(path: Path, get_snapshot, stop: threading.Event) -> threading.Thread:
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    # A daemon killed with -9 leaves the file behind and bind() refuses an
    # existing path. Unhandled, the fleet cannot be restarted after exactly the
    # failure it is designed to survive.
    with contextlib.suppress(FileNotFoundError):
        path.unlink()

    server = socket.socket(socket.AF_UNIX, socket.SOCK_STREAM)
    server.bind(str(path))
    server.listen(_BACKLOG)
    # A timeout rather than a blocking accept: without it the thread cannot
    # notice `stop` and the daemon hangs on shutdown until someone connects.
    server.settimeout(_TIMEOUT)

    def loop() -> None:
        try:
            while not stop.is_set():
                try:
                    connection, _ = server.accept()
                except socket.timeout:
                    continue
                with connection:
                    snapshot = get_snapshot()
                    payload = snapshot.to_json() if snapshot is not None else {}
                    connection.sendall((json.dumps(payload) + "\n").encode("utf-8"))
        finally:
            server.close()
            with contextlib.suppress(FileNotFoundError):
                path.unlink()

    thread = threading.Thread(target=loop, name="fleet-statesocket", daemon=True)
    thread.start()
    return thread


def request(path: Path) -> dict:
    client = socket.socket(socket.AF_UNIX, socket.SOCK_STREAM)
    client.settimeout(2.0)
    try:
        client.connect(str(path))
    except (FileNotFoundError, ConnectionRefusedError) as exc:
        raise NotRunning(f"no fleet daemon listening on {path}") from exc
    try:
        chunks = []
        while True:
            chunk = client.recv(65536)
            if not chunk:
                break
            chunks.append(chunk)
    finally:
        client.close()
    return json.loads(b"".join(chunks).decode("utf-8") or "{}")
```

```python
from __future__ import annotations
```

```python
def render(payload: dict) -> list[str]:
```
